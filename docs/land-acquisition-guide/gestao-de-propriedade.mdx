# Gestão de Propriedade para Investidor Remoto
## Como Terceirizar o Gerenciamento do Seu Imóvel nos EUA

> **Premissa:** Você construiu o imóvel, optou pela estratégia de refinanciar e alugar (BRRRR), e agora precisa de alguém de confiança para operar o ativo a 9.000 km de distância.

---

## Autogestão vs. Property Manager

Para um investidor estrangeiro morando no Brasil, **autogestão não é viável** na prática. A lei americana exige respostas rápidas a solicitações de manutenção (em alguns estados, até 24–48h), e o fuso horário torna tudo mais difícil.

| Fator | Autogestão | Property Manager |
|-------|-----------|-----------------|
| Custo | Zero (taxa) | 8%–12% do aluguel bruto |
| Disponibilidade emergências | Inviável do Brasil | 24/7 |
| Triagem de inquilinos | Você faz | PM faz (com critérios) |
| Conformidade legal (Fair Housing) | Risco alto para estrangeiro | PM assume responsabilidade |
| Coleta de aluguel | Manual | Automática |
| Relatórios financeiros | Você controla | Mensais via software |
| Tempo investido/mês | 10–20h | < 1h (revisão de relatório) |

> **Conclusão:** Para investidor brasileiro, property manager é uma despesa operacional obrigatória, não opcional. Inclua no pro forma desde o início.

## Quanto Custa um Property Manager

### Estrutura de Taxas Típica

| Taxa | Valor Típico | O Que Cobre |
|------|-------------|-------------|
| **Taxa de gestão mensal** | 8%–12% do aluguel bruto | Coleta, manutenção, relatórios, atendimento |
| **Taxa de locação** | 50%–100% do primeiro mês | Encontrar e selecionar inquilino |
| **Taxa de renovação** | US$150–US$300 | Renovar contrato com inquilino existente |
| **Taxa de desocupação** | 0 | PM não cobra quando imóvel está vago |
| **Manutenção** | Custo real + 10%–15% markup | Reparos executados pelo PM |
| **Taxa de inspeção** | US$75–US$150 | Inspeções periódicas (semestrais) |

### Exemplo de Custo Real (Duplex, US$2.400/mês de aluguel)

| Item | Cálculo | Custo/Mês |
|------|---------|----------|
| Taxa de gestão (10%) | US$2.400 × 10% | US$240 |
| Taxa de locação (amortizada) | US$2.400 ÷ 12 meses | US$200 |
| Manutenção estimada | 5% do aluguel | US$120 |
| Reserva para vacância (5%) | US$2.400 × 5% | US$120 |
| **Total estimado** | | **US$680/mês** |
| **Aluguel líquido** | US$2.400 − US$680 | **US$1.720/mês** |

> Sempre use o aluguel líquido (net rent) no cálculo de DSCR — não o aluguel bruto.

## Como Encontrar um Bom Property Manager

### Fontes de Busca

1. **NARPM (National Association of Residential Property Managers)** — narpm.org
   - Busque PMs certificados (NARPM Members) na sua cidade-alvo
   - Membros seguem código de ética e treinamento obrigatório

2. **BiggerPockets** — biggerpockets.com/forums
   - Fóruns por cidade/estado — peça indicação de membros locais

3. **Referência do seu corretor imobiliário local**
   - Corretores que trabalham com investidores frequentemente indicam PMs de qualidade

4. **Google Maps** — busca "property management [cidade]"
   - Filtre por avaliações > 4.5 estrelas com > 50 reviews

### Checklist de Vetting do Property Manager

**Perguntas para fazer por telefone ou videochamada:**

- [ ] Qual o número de imóveis que vocês gerenciam atualmente?
   *(resposta ideal: 100–500 unidades — nem pequeno demais, nem grande demais para você)*
- [ ] Qual a taxa de ocupação média do portfólio de vocês?
   *(aceitável: > 93%)*
- [ ] Como funciona o processo de triagem de inquilinos?
   *(deve incluir: verificação de crédito, renda mínima 3x aluguel, histórico criminal)*
- [ ] Como funciona a resposta a manutenções emergenciais?
   *(deve ter: linha 24/7, prazo de resposta < 4h para emergências)*
- [ ] Vocês têm experiência com proprietários internacionais?
   *(importante: envio de fundos para conta estrangeira, reporting para fins fiscais)*
- [ ] Qual o software que vocês usam para relatórios?
   *(deve ser: AppFolio, Propertyware, Buildium ou similar — não planilha Excel)*
- [ ] Posso falar com 2–3 proprietários que vocês gerenciam atualmente?
   *(PM de qualidade não hesita em fornecer referências)*
- [ ] Como funciona a saída do contrato se eu não ficar satisfeito?
   *(ideal: aviso de 30–60 dias, sem multa)*

### Sinais de PM de Qualidade vs. Problema

| PM de Qualidade | PM Problemático |
|----------------|----------------|
| Responde em < 24h | Demora dias para responder |
| Software profissional (AppFolio, etc.) | Relatórios em Excel ou papel |
| Processo de triagem documentado | Triagem informal ou "a critério do PM" |
| Referências disponíveis prontamente | Hesita em fornecer referências |
| Contrato transparente | Taxas escondidas no contrato |
| Reserva de manutenção clara | Faz manutenção sem avisar ou aprovação |
| Relatórios mensais padronizados | Relatórios esporádicos ou verbais |

## O Contrato de Property Management

### Cláusulas Essenciais para Proteger o Investidor Brasileiro

```
REVISAR ANTES DE ASSINAR:

1. AUTORIDADE DE MANUTENÇÃO
   "PM pode aprovar reparos até US$_____ sem consultar o proprietário"
   (recomendado: US$300–US$500 para imóvel único / US$500–US$1.000 para duplex)
   Acima desse valor: PM deve obter aprovação por escrito antes de executar.

2. REPASSE DE FUNDOS
   "PM repassa aluguel líquido até o dia ___ de cada mês"
   Incluir instrução de wire transfer para conta LLC americana
   (o PM geralmente não envia diretamente para conta no Brasil)

3. RESERVA DE OPERAÇÃO
   PM retém reserva mínima na conta do imóvel (US$500–US$1.500)
   para cobrir manutenções urgentes sem necessidade de wire transfer rápido.

4. RESCISÃO
   "Proprietário pode rescindir com 30 dias de aviso, sem multa"
   Evite contratos com multa rescisória ou prazo mínimo > 1 ano.

5. EXCLUSIVIDADE DE FORNECEDORES
   Verifique se PM usa seus próprios subcontratados — se sim, confirme
   que os preços são competitivos (risco: markup excessivo).

6. RELATÓRIOS FISCAIS
   PM deve emitir Form 1099-MISC anual se aluguéis pagos > US$600
   (necessário para declaração de imposto de renda nos EUA)
```

## Triagem de Inquilinos: Entendendo o Processo

O PM faz a triagem, mas você precisa entender os critérios para garantir que sejam adequados.

### Critérios Padrão de Triagem

| Critério | Parâmetro Recomendado |
|---------|----------------------|
| **Renda mínima** | 3x o valor do aluguel (antes de impostos) |
| **Crédito** | Score mínimo 620+ (620–679 = aprovado com depósito maior) |
| **Histórico de aluguel** | Sem despejos nos últimos 5 anos |
| **Histórico criminal** | Sem crimes violentos ou relacionados a drogas |
| **Emprego** | Empregado há mínimo 6 meses ou renda verificável |

### Fair Housing Act — O Que Você Não Pode Fazer

A lei federal americana proíbe discriminação por:
- Raça, cor, religião, sexo, origem nacional
- Deficiência física ou mental
- Situação familiar (crianças)

> Nunca diga (nem implique) preferência por tipo de inquilino fora dos critérios financeiros. Deixe sempre o PM conduzir a triagem — ele conhece as leis locais.

## Ciclo Mensal com o Property Manager

### O Que Você Deve Receber Todo Mês

- [ ] **Extrato financeiro** (Owner Statement): receitas, despesas, saldo
- [ ] **Status de ocupação**: imóvel alugado, vacante, em transição
- [ ] **Manutenções realizadas**: descrição, valor, fornecedor
- [ ] **Data do repasse** e valor transferido
- [ ] **Alertas**: atraso de aluguel, renovação de contrato, notificação de saída

### Sua Revisão Mensal (< 1 hora)

1. Confirmar recebimento do repasse na conta LLC
2. Revisar o Owner Statement — comparar com mês anterior
3. Verificar manutenções — valor razoável? Já aprovadas?
4. Verificar status do inquilino — contrato vai vencer?
5. Atualizar planilha de fluxo de caixa (comparar com pro forma original)

## Gestão de Vacância

Vacância é o maior inimigo do fluxo de caixa. O PM deve ter processo ativo:

### Cronograma de Resposta à Vacância

| Momento | Ação do PM |
|---------|-----------|
| **60 dias antes do fim do contrato** | Contato com inquilino sobre renovação |
| **30 dias antes** | Decisão de renovar ou anunciar |
| **Saída do inquilino** | Inspeção de move-out + checklist de danos |
| **Primeiros 7 dias** | Fotos profissionais + anúncio ativo (Zillow, Apartments.com, Zumper) |
| **Primeiros 30 dias** | Mínimo 3 visitas por semana |
| **Após 45 dias vago** | Revisão de preço + PM apresenta relatório de mercado |

### Taxas de Vacância por Mercado (Referência 2024–2025)

| Mercado | Taxa de Vacância | Prazo Médio para Locar |
|---------|-----------------|----------------------|
| Jacksonville, FL | 4%–6% | 18–28 dias |
| San Antonio, TX | 5%–7% | 20–32 dias |
| Memphis, TN | 6%–9% | 22–35 dias |
| Tampa, FL | 3%–5% | 14–22 dias |
| Charlotte, NC | 4%–6% | 18–28 dias |

> Para o pro forma, use **vacância de 8%** como premissa conservadora — equivale a ~1 mês vago por ano.

## Manutenção Preventiva: Proteja o Ativo

Uma propriedade nova (sua construção) tem menos manutenção nos primeiros 5 anos. Mesmo assim, orçamento:

### Reserva de Manutenção Recomendada

| Tipo de Imóvel | Reserva Mensal Recomendada |
|---------------|--------------------------|
| SFR novo (< 5 anos) | 0,5%–1% do valor do imóvel/ano |
| Duplex novo (< 5 anos) | 0,75%–1,5% do valor/ano |
| Imóvel existente (> 10 anos) | 1%–2% do valor/ano |

**Exemplo:** SFR construído, valor US$380.000
- Reserva: 1% ao ano = US$3.800/ano = **US$317/mês**
- Inclua na planilha de fluxo de caixa como despesa fixa

### Checklist de Manutenção Anual (envie ao PM)

- [ ] Limpeza e inspeção de calhas (gutters) — março e outubro
- [ ] Revisão do sistema de HVAC — antes do verão e inverno
- [ ] Inspeção do telhado — após temporada de chuvas
- [ ] Verificação de detectores de fumaça e CO
- [ ] Inspeção de encanamentos — áreas com risco de congelamento
- [ ] Revisão de impermeabilização externa
- [ ] Controle de pragas (pest control) — trimestral

## Implicações Fiscais da Renda de Aluguel

### Obrigações nos EUA

- Renda de aluguel reportada no **Form 1040-NR** (não-residente) + **Schedule E**
- Depreciação do imóvel dedutível: vida útil de 27,5 anos para residencial
- Despesas dedutíveis: PM fees, manutenção, seguro, juros do DSCR, IPTU (property tax), depreciação
- **ITIN obrigatório** para declarar — sem ITIN, o IRS pode tributar 30% bruto sobre renda de aluguel

### Obrigações no Brasil

- Renda de aluguel recebida no exterior declara no **DIRPF** (Carnê-leão se receber > R$2.824/mês)
- Imóveis mantidos no exterior declaram na **Declaração de Bens e Direitos** (sem limite mínimo)
- Se valor total de ativos no exterior ≥ US$1M → **CBE** (Banco Central do Brasil) obrigatório

> Veja o módulo [Jurídico e Fiscal](/land-acquisition-guide/legal-tax) para detalhes completos sobre FIRPTA, ITIN e CBE.

## Resumo: Checklist do Property Manager

### Antes de Contratar
- [ ] Verificar se PM é membro da NARPM
- [ ] Checar avaliações no Google e BBB
- [ ] Entrevistar mínimo 3 PMs antes de escolher
- [ ] Falar com pelo menos 2 referências de proprietários atuais
- [ ] Revisar o contrato com advogado (cláusulas de rescisão, taxas, autoridade)

### Ao Contratar
- [ ] Conta bancária da LLC configurada para receber repasses
- [ ] Autoridade de manutenção definida (limite de valor sem aprovação)
- [ ] Reserva operacional depositada na conta do PM
- [ ] Acesso ao portal do proprietário (AppFolio ou similar) ativado
- [ ] Calendário de relatórios mensais confirmado

### Mensalmente
- [ ] Repasse recebido na data combinada
- [ ] Owner Statement revisado
- [ ] Manutenções aprovadas e dentro do orçamento
- [ ] Planilha de fluxo de caixa atualizada
- [ ] Carnê-leão pago se necessário (Brasil)
