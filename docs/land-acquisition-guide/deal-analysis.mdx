# Attachment 4 — Deal Analysis & Pro Forma Template
## Ground-Up Development | SFR & 2–4 Unit Multi-Family

> Run this analysis BEFORE making an offer on land. If the numbers don't work at the land price, negotiate down or walk away. The pro forma tells you the maximum you can pay for land and still hit your return targets.

---

## How to Use This Template

1. Fill in the **blue cells** (your inputs) for each deal
2. The template calculates profit, ROI, and cash-on-cash return
3. Use the **"Max Land Price"** calculation to set your offer ceiling
4. Run both Exit Scenarios (Sell vs. Refi) before committing

## MODULE 8: MAXIMUM LAND PRICE CALCULATOR

Work backwards from your profit target to find the maximum you should pay for land.

### For Sell Exit:

```
Max Land Price = ARV × Target Margin% − Construction Cost − Financing Cost − Holding Cost − Sale Costs
```

**Example:**
```
ARV:                    $400,000
Target Gross Margin:    × 20%     =  $80,000 minimum profit
ARV - Profit:                        $320,000
Construction Cost:                  −$210,000
Financing Cost:                     −$22,000
Holding Cost:                       −$8,000
Sale Costs (6%):                    −$24,000
────────────────────────────────────────────
Max Land Price:                      $56,000
```

### For DSCR Refi Exit:

The land price is constrained by:
1. Your total cash requirement (land + 25–30% of construction loan)
2. The DSCR loan must cash flow at refi

## Quick Reference: Rule-of-Thumb Checks

### 70% Rule (Sell Exit)
```
Max All-In Cost ≤ ARV × 70%
```
If your total project cost exceeds 70% of ARV, the deal likely doesn't pencil for a flip.

### 1% Rule (Refi/Rent Exit)
```
Monthly Rent ÷ Total Project Cost ≥ 1%
```
Example: $2,500 rent ÷ $300,000 total cost = 0.83% — slightly below 1% (acceptable in low-cap-rate markets)

*Note: The 1% rule is a quick screen, not a comprehensive analysis. Always run full DSCR numbers.*
