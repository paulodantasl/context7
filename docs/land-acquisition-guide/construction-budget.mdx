## Section 7: Project Timeline

### SFR — Estimated Timeline (12–18 months total)

| Phase | Duration | Milestone |
|-------|---------|-----------|
| Market research & team assembly | 4–8 weeks | GC, lender, agent identified |
| Land search & due diligence | 4–12 weeks | Lot under contract |
| Closing on land | 2–4 weeks | Land purchased |
| Architectural plans | 4–8 weeks | Plans complete |
| Permit submission | 1–2 weeks | Plans submitted |
| **Permit approval** | **4–24 weeks** | **Biggest variable by market** |
| Construction financing closing | 2–4 weeks | Loan funded |
| Site work & foundation | 3–6 weeks | Foundation complete → Draw 1 |
| Framing | 3–5 weeks | Framing complete → Draw 2 |
| Roofing & exterior | 2–4 weeks | Dried-in |
| MEP rough-in | 3–5 weeks | Rough-in complete → Draw 3 |
| Insulation & drywall | 2–3 weeks | Drywall complete → Draw 4 |
| Interior finishes | 4–8 weeks | Finishes complete → Draw 5 |
| Final punch list & CO | 2–4 weeks | CO received → Draw 6 |
| **Exit (sell or refi)** | **4–8 weeks** | **Sold or refinanced** |
| **Total from land search to exit** | **~14–22 months** | |

### Critical Timeline Notes
- **Permitting** is the biggest wildcard — can range from 4 weeks to 18+ months depending on city/county
- Fast-permit markets (Jacksonville, San Antonio, Memphis): 6–12 weeks
- Slow-permit markets (Miami, Austin, Denver): 6–18 months
- **Always confirm permit timelines BEFORE buying land**

## Section 8: General Contractor Selection

### What to Look For

- [ ] Licensed in the state where you're building
- [ ] General Liability Insurance (minimum $1M per occurrence)
- [ ] Workers' Compensation Insurance
- [ ] Track record of similar projects (SFR or multifamily new construction)
- [ ] References from recent clients
- [ ] Financial stability (can float some costs between draws)
- [ ] Clear communication style (important for remote management)
- [ ] Experience working with investor clients (not just custom home buyers)

### Red Flags
- Requests full payment upfront
- No written contract
- Cannot provide proof of insurance
- No local license
- Pressure to skip permits or inspections

### GC Contract Key Terms

| Term | What to Negotiate |
|------|------------------|
| Contract type | Fixed-price (preferred) vs. cost-plus |
| Draw schedule | Tied to inspections, not calendar dates |
| Completion date | With penalty clause for delays |
| Change order process | Written approval required for all changes |
| Warranty | Minimum 1 year on workmanship |
| Lien waiver | Required with each draw payment |
| Retainage | Withhold 5–10% until final completion |

### Getting Bids

Always get **3 competing bids** for projects over $100K. Present the same architectural plans and scope to each GC for apples-to-apples comparison.

| Bid Component | Check |
|--------------|-------|
| Scope is complete (no missing line items) | |
| Inclusions and exclusions clearly listed | |
| Materials specified (grade, brand, or equivalent) | |
| Timeline stated | |
| Payment schedule matches draw schedule | |
| Permit fees included or excluded (stated clearly) | |
